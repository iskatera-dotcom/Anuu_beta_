# For Anuu ♡ — Himanshu's little love website

A responsive pink romantic website with lots of cute animations, your five photos, a letter, shayari carousel, mini-game, photo lightbox, surprise reveal, floating hearts, confetti and optional music.

## Files
- `index.html` — website content
- `style.css` — pink theme, responsive layout and animations
- `script.js` — interactive features
- `assets/memory-1.jpeg` through `assets/memory-5.jpeg` — your uploaded photos
- Optional: `assets/soft-romantic.mp3` — add a music file you have the right to use

## Preview on your computer
Open `index.html` in a browser. For the best experience, use a simple local server or GitHub Pages.

## Publish with GitHub Pages (phone or computer)
1. Sign in at https://github.com and create a **new public repository**, e.g. `for-anuu`.
2. Upload **all files and the `assets` folder** from this ZIP. Make sure `index.html`, `style.css`, and `script.js` are in the repository's root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then press **Save**.
6. Wait a minute or two. GitHub Pages will show a link like `https://YOUR-USERNAME.github.io/for-anuu/`. Open it and send the link to Anuu.

## Add music
The music button is wired to `assets/soft-romantic.mp3`. Put a romantic instrumental MP3 that you own or are authorized to use in that exact location/name, then upload the updated assets folder. Browsers usually require a tap before music can start, so the site uses a play button rather than auto-playing.

## Personalize it
- The letter and messages are in `index.html`.
- Shayari options and game replies are in `script.js`.
- Photo captions are in `index.html`. The existing five photo files are already linked.
- To swap a photo, replace the corresponding `assets/memory-N.jpeg` while keeping the same filename.

## Privacy note
This is a static website. Anyone who has the public GitHub Pages link can view it. Only publish photos and personal details that both of you are comfortable sharing publicly. You can use a private repository depending on GitHub Pages availability and plan settings, or keep the photos off the public site.
